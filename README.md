# Chapters

Illustrated mushaf page themes for selected Quran chapters, used in iOS reader apps by **Muhammad Mujahid Khan**.

## Chapters

| Folder | Surah |
|--------|--------|
| [`yaseen`](./yaseen) | Surah Yaseen (Yasin) — 36 |
| [`mulk`](./mulk) | Surah Al-Mulk — 67 |
| [`rahman`](./rahman) | Surah Ar-Rahman — 55 |
| [`kahf`](./kahf) | Surah Al-Kahf — 18 |
| [`maryam`](./maryam) | Surah Maryam — 19 |
| [`waqiah`](./waqiah) | Surah Al-Waqi'ah — 56 |

Each chapter folder includes theme variants (for example classic, emerald, illuminated, night, parchment) with page images.
